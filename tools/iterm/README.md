# Профиль iTerm2 «TermitRun»

Отдельный профиль для игры: тёмный неон-нуар (розовый, циан, кислотный лайм), окно 80×32,
шрифт — моноширинный по умолчанию твоего iTerm2. Открывает папку проекта и сразу
запускает `./termit`; после выхода из игры остаётся обычный zsh. Твой `~/.zshrc` и
остальные профили не меняются.

Поставить (одна команда из папки проекта):

    sh tools/iterm/install.sh

Скрипт подставит путь к проекту и положит профиль в
`~/Library/Application Support/iTerm2/DynamicProfiles/TermitRun.json`. iTerm2 подхватит
его сам: Profiles → TermitRun (или Cmd+O и ввести «TermitRun»).

Удалить:

    sh tools/iterm/install.sh --remove

Тренажёр этот скрипт никогда не вызывает — только ты сам. Графику в любом терминале можно
упростить: `TERMIT_PLAIN=1` (чистый текст, для скринридеров), `TERMIT_NO_ANIM=1` (без
печатающихся заголовков), `NO_COLOR=1` (без цвета).
