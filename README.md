# TermitRun — игра, в которой учишься терминалу

Сан-Франциско будущего. Корпорации, деккеры, вернувшаяся в мир магия — а твоя дека
это обычный терминал macOS. Каждый заход в игру — **ран**: несколько коротких заданий,
которые решаются настоящими командами командной строки. Шаг за шагом терминал
перестаёт пугать и становится удобнее, чем Finder.

Задания проверяются сами после каждой твоей команды, есть подсказки, разбор решения
и повторение пройденного по расписанию — чтобы команды запоминались надолго.

## Это первый модуль

Сейчас открыт **модуль «Основы»**: как понять, где ты находишься, ходить по папкам,
находить файлы, создавать папки, копировать и переносить файлы, выбирать их по маске
имени — то, с чего начинается любая работа в терминале.

Дальше — больше. Следующие модули уже в работе:

- Инструменты
- Вместо Finder
- Данные
- Базы данных
- SQL и PostgreSQL
- Окружение и скрипты
- Python
- Аналитика

В игре их места уже видны на карте с пометкой «скоро». **Нам очень нужны активные
тестеры** — играй, ломай, пиши, что думаешь.

## Что нужно

- **macOS** — задания идут в песочнице на встроенном в систему `sandbox-exec`.
  Windows и Linux пока не поддерживаются.
- **Python 3.9 или новее** — проверить: `python3 --version`. Если команда не найдена,
  macOS сама предложит поставить инструменты разработчика — соглашайся.
- **zsh** — стоит в macOS по умолчанию, ничего делать не нужно.

## Терминал, iTerm2, zsh — что это и что поставить

- **Терминал** — окно-программа, в котором набирают команды. В каждом Mac уже есть
  встроенный «Терминал» (Terminal.app) — его хватит, ставить ничего не обязательно.
- **iTerm2** — тот же терминал, только удобнее: вкладки, деление окна на части, поиск по
  выводу, профили. Бесплатный. Поставить по желанию: скачать с [iterm2.com](https://iterm2.com)
  и перетащить в «Программы». Если уже есть Homebrew (менеджер программ, в игре он появится
  позже, в «Инструментах») — одной командой: `brew install --cask iterm2`.
- **Оболочка (shell)** — программа внутри окна, которая понимает твои команды и запускает
  их. В macOS с 2019 года это **zsh**; bash — старая оболочка, её чаще встретишь на
  серверах. zsh уже стоит, проверить: `echo $SHELL` — ответ `/bin/zsh`.
- **Команда** — тоже программа: `ls`, `cd`, `cat`… Оболочка находит её и запускает.

Зачем всё это, если есть Finder? Одна строка делает работу сотни кликов, команды можно
сохранить и повторять, а на серверах и в программировании окон с мышью нет вовсе.

Для iTerm2 в игре есть свой профиль оформления «TermitRun»: `sh tools/iterm/install.sh`
(подробности — в `tools/iterm/README.md`). Это необязательно: игра работает в любом терминале.

### У меня bash

Ничего страшного: игру можно запускать из любой оболочки, а задания всё равно идут
в её собственном zsh. Но кое-что из выученного в bash не сработает или сработает
по-другому — в игре такие места помечены значком 🐚. Из «Основ» это:

- `**` (маска «на любой глубине») — в bash на Mac работает как простая `*`;
- уточнения в скобках после маски, вроде `(D)`, — bash их не знает и ругается;
- Ctrl+U стирает не всю строку, а только то, что левее курсора;
- голая `history` в bash выдаёт всю историю, а zsh — последние 16 команд;
- `setopt` — команда zsh, в bash настройки включают `shopt -s` и `set -o`; файл настроек
  у bash не `~/.zshrc`, а `~/.bash_profile`.

Попробовать zsh можно прямо сейчас, ничего не меняя: набери `zsh` и Enter — ты в zsh.
Вернуться в bash — `exit`.

## Как начать

Открой «Терминал» (Cmd+Пробел, набери «Терминал», Enter) и введи по очереди:

```sh
git clone https://github.com/AlexPako/termitrun.git
cd termitrun
./termit
```

Откроется убежище: Enter делает то, что отмечено ⏎, все слова — help, выйти — quit.
Игра сама всё расскажет. Лучше играть понемногу каждый день: ран занимает минут десять.

Пригодится:

- `quit` — выйти из задания (прогресс сохранится), `hint` — подсказка,
  `skip` — отложить задание;
- `keys` — шпаргалка по клавишам: как вернуть прошлую команду, прокрутить экран и т.п.;
- `bug` — написать замечание прямо из задания;
- `help` — все слова игры, `map` — карта (внутри убежища).

Следующий раз — просто `cd termitrun` и `./termit`.

## Как пользоваться убежищем

1. Набери `./termit` в папке игры. Откроется **убежище** — главный экран игры, из него
   делается всё остальное. В самый первый раз игра сразу открывает первое задание, а
   убежище покажет после него.
2. Сверху — **пульт**: что сегодня можно сделать (ран дня, новые сообщения, отработка…).
   Справа у строк — слово, которое её открывает.
3. Внизу — приглашение `убежище › `. Сюда набирают короткие **слова игры** и жмут Enter.
   Это не команды терминала: `ls` и `cd` пробуют внутри задания.
4. **Просто Enter**, ничего не набирая, делает самое нужное сейчас — то, что отмечено ⏎ в
   строке над приглашением. Не знаешь, что делать, — жми Enter.

Главные слова:

| Слово   | Что делает                                                    |
|---------|---------------------------------------------------------------|
| `run`   | ран дня, ~10 минут — главное дело дня                         |
| `new`   | ещё урок: новые команды сверх нормы (`more` — то же самое)    |
| `train` | отработка: повторить то, что получалось хуже                  |
| `inbox` | сообщения на деке; `inbox next` — прочитать новое             |
| `home`  | твоя комната с вещами                                         |
| `shop`  | витрина: что можно купить                                     |
| `help`  | все слова по группам; `help СЛОВО` — подробно об одном        |
| `quit`  | выйти из игры (Ctrl+D — то же)                                |

Остальные слова открываются по ходу игры — подсказка над приглашением сама скажет о новом.
После рана ты снова в убежище; `quit` внутри задания тоже возвращает сюда.

Отработка (`train`) — спортзал для слабых мест, отдельно от рана:

- `train` — три задачи, которые у тебя выходили хуже всего (сдавался, брал подсказку, сбивался);
- `train ТЕМА` — знакомое из одного места (`train basics`) или по одной команде (`train grep`);
- `train ID` — одна конкретная задача (`play ID` — то же самое); стражей отработка не трогает;
- `train exam` — 5 знакомых заданий вперемешку, на время.

Отработка не платит, не даёт кармы, не держит серию и не двигает расписание: это просто
повторение. Одну задачу отрабатывают раз в день — память крепнет с перерывом.

## Безопасно ли это

Да. Каждое задание идёт в отдельной папке-песочнице: команды видят только её,
твои настоящие файлы и папки игра не трогает и удалить их из задания нельзя.
Песочница убирается за собой сама. Весь прогресс лежит в папке игры
(`progress.json`) — удалишь папку, и следов не останется.

## Обновление

Когда выйдет новая версия, игра сама скажет об этом: «📦 Вышло обновление игры» (проверка
идёт не чаще раза в сутки и ничего о тебе не отправляет — это обычный запрос git к
репозиторию). Чтобы обновиться, набери в убежище `update` (или `./termit update`) — или
просто `git pull` в папке игры. Прогресс не пропадёт: `progress.json` лежит вне репозитория.
Если ты менял файлы игры, `update` ничего не тронет и подскажет, что делать. Отключить
проверку: `TERMIT_NO_UPDATE_CHECK=1`.

## Баги и идеи — пишите!

Пишите **не только баги, но и идеи, пожелания и что было непонятно** — всё это ценно.
Если задание показалось запутанным, это не ты чего-то не понял, а игре есть что улучшить.

- **Прямо из игры:** в задании набери `bug` и опиши, что не так. Игра запишет замечание
  и покажет ссылку на готовую карточку — открой её (Cmd+клик), проверь текст и нажми
  Submit.
- **Без игры:** `./termit report` покажет ссылки, или сразу открой
  [Issues](https://github.com/AlexPako/termitrun/issues) → New issue.

Для карточки нужен бесплатный аккаунт GitHub. В неё попадает только то, что ты сам
написал, номер задания и версия macOS — без имени пользователя и путей к твоим файлам.

Следи за репозиторием (кнопка Watch), чтобы не пропустить следующий модуль.
